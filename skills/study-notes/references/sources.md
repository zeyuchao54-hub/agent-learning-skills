# Sources, policies, and revisions

Identify the source's role before using it. A syllabus or handbook can establish published assessment rules, but is not automatically the best authority for a mathematical claim. A later official correction can supersede an earlier document. Record conflicting versions and the basis for preferring one.

Ingest the relevant supplied materials. Use an available text extractor for documents with a text layer; use OCR or visual reading where needed. Do not assume a particular executable or PDF skill is installed. If extraction is incomplete or a page is unreadable, identify the gap instead of inventing content. For screenshots, verify their order and capture any visible version date.

Write original explanations and concise summaries with locators. Supplementary knowledge is welcome when useful, but label it as explanation or cite the supplementary source. If the learner requests a strictly source-only summary, obey that boundary. Preserve names, numerical weights, dates, units, and required output precisely. Record an absent year or timezone as absent rather than supplying one by guesswork.

For course information, include the supplied course identity, learning outcomes, published schedule, assessment weight/date table, and relevant rules or references. Do not require such a page for self-study without institutional assessment. Missing fields are “not stated”; inconsistent weights or suspicious dates should be flagged. Quote exact wording only where needed and permitted, rather than copying a complete handbook by default. The open-source skill package must not include third-party teaching materials or a real learner's private record.

For revisions, retain useful still-correct annotations, update affected claims in place, and record the source version or correction date. If a linked reference sheet, overview, or learning plan repeats the changed fact, reconcile it. Updating source coverage does not update learning achievement.
