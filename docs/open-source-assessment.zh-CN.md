# 开源价值评估

评估日期：2026-10-05。结论：值得整理并开源，但应定位为可配置的教学与笔记工作流，而非宣称没有同类、适用于任何人，或已经证明能提高成绩。

## 原版本可复用的机制

- **路径、验证和题源分离**：课堂进度与作业需求可能不同；识别正确答案与独立产出也不同。
- **状态、偏好、知识和证据分工**：持续对话可以用小型状态索引恢复，而不是每次通读所有笔记。
- **真实错误记录**：具体错在哪一步比通用“注意事项”更有复习价值；同时保留补讲和重测的关联。
- **笔记维护纪律**：资料变化后同步修正；速查引用详细解释；不制造空壳笔记；既有长篇笔记得到保留。
- **轻量协作**：教学与笔记可独立使用，配合时共享明确配置，不需要数据库、专用服务或多代理编排。

这些都是工程和交互层面的价值判断。其教育效果仍需真实用户反馈或设计合适的学习实验验证。

## 必须剥离的个人前提

| 原有前提 | 通用处理 |
| --- | --- |
| 指定学校、课程码和课程目录 | 明确指定任意学习工作区与主题 |
| 中文理解、英文应试 | 教学语言、考核语言、笔记语言独立可选 |
| 输入公式不方便，所以都用选择题 | 支持简写、解释、推导、产出物与替代输入 |
| 固定百分比和题数放行 | 先声明适合目标的证据与标准，比例只是可调整默认值 |
| 固定“学习风格”与个人事故 | 根据当前偏好和实际表现调整，移除个人记录 |
| 强制中文文件名与双语标题 | 遵循目标笔记库和语言设置 |
| 只许使用课件现有知识 | 来源可追踪；补充内容注明来源；支持明确的 source-only 模式 |
| 概念页一律从头重写 | 修正受影响部分并保护有效推导与个人注释；快照刷新可重写 |
| 默认抄录整个 handbook | 默认提炼来源明确的课程信息，准确保留关键数值和规则 |
| 不同文件使用不同状态预算 | 统一为默认 state 120 行、memory 90 行，并通过归档保留历史 |

另外，原有“强制换答案位置 + 均衡分布”不等于随机化。通用版先解题、生成选项，再随机打乱并核对正解；不会因为短序列自然重复就作废测验，也不改已经发出的选项。

## 发布建议

以“适配目标的持续辅导 + 可追溯笔记维护”描述项目，公开两个可单独安装的技能、轻量初始化工具、配置示例和验证流程。保留 MIT 许可及来源说明，使用虚构演示资料。先收集不同学科、语言和宿主的反馈，再决定是否增加题库、数据库、提醒系统或插件包装。

当前交付适合作为首个公开版本的候选包。规模很小，维护成本可控；真正的差异应由使用体验体现，而不是通过“首个”“最强”“保证掌握”来宣称。
