# 从个人版迁移

通用技能使用新名字 `learning-tutor`、`study-notes`，不会替换已安装的个人版 `teaching-tutor`、`course-notes`。也不会自动搬运旧课程或读取个人档案。你可以保留个人版继续用于原有课程，把通用版单独发布。

## 新用户

安装需要的技能，指定一个工作区，然后说明目标、材料和语言。无需学校结构、课程码或笔记软件。无文件访问时使用聊天交接摘要即可。

## 已有学习状态

1. 备份已有状态和笔记，选定要迁移的单个学习主题。
2. 建立新工作区，以 `--notes-format none` 初始化，避免触碰原有笔记。
3. 从旧 `config.md` 提炼真正仍需要的偏好，写入 `.learning/config.json`；不要默认带入强制双语、选择题和个人化教学标签。
4. 把阶段清单、目标、通过条件和已验证状态放进 `.learning/plan.md`。把当前断点、待答问题、资料指针和未解决项放进 `STATE.md`。旧摘要中的“已通过”须有作答证据支撑，证据不足则注明。
5. 复制真实作答历史为独立的旧档案并从 `attempts.md` 链接，新记录继续追加。保留原日期、错误及后续订正，不把历史改写成更整齐但失真的成绩。
6. 把仍有效的明确偏好和有证据的观察整理到 `memory.md`。通过 `notes.directory` 指向原笔记库，再启用笔记；语言和风格沿用用户选择。
7. 运行一次恢复会话，检查下一步和证据是否一致，再决定是否停用旧技能。

这是一份人工审阅迁移流程。没有自动迁移脚本；两套状态格式和历史记法差异较大，自动推断会制造假的“已掌握”。

## 发布前的数据边界

公开目录仅保留技能、通用模板、虚构配置和测试。不要把学习工作区、真实作答、偏好档案、学号、账户配置、教师联系信息或第三方课件复制进去。模板中的 `{{title}}` 等标记用于生成新页面，不是私人数据。开源目录与学习目录分开维护；个人适配保留在本地设置中。
